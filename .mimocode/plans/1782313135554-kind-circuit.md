# Fix: Chat app 401 after login — wrong localStorage key

## Problem

The chat app stores the JWT token under `chat-token` in localStorage (in `authSlice.ts` and `http.ts`), but `apps/chat/src/services/ai.ts` line 37 reads from `user-token` — the key used by the web app. Since `user-token` doesn't exist in the chat app's localStorage, `getChatStreamHeaders()` sends no `Authorization` header, causing 401 on all protected API calls.

## Fix

**Single change in one file:**

`apps/chat/src/services/ai.ts` line 37:
```diff
- const token = localStorage.getItem('user-token');
+ const token = localStorage.getItem('chat-token');
```
